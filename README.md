# CSSE3030 Practical Resources

Base scaffold for CSSE3030 practical exercises. This branch has no
practical-specific content — each week's exercises live on their own
branch, branched off `main`:

- `week3`
- `week4`
- `week5`
- etc.

After cloning this repository `git clone https://github.com/mferr11/CSSE3030Practicals.git` switch your branch to the current week's exercies using `git checkout <branch-title>`, such as `git checkout week3` for example.
